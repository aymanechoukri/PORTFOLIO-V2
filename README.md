# Aymane Chokri — Portfolio

A responsive, animated developer portfolio built with Next.js, React, TypeScript, Tailwind CSS, and Framer Motion.

## Highlights

- Responsive portfolio layout with mobile navigation
- Animated hero and interactive 3D-style project cards
- Selected projects with source-code and live-demo links
- About, skills, experience, education, services, and contact sections
- Social links and direct email contact
- SEO metadata, accessible focus states, and reduced-motion support

## Tech stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- React Icons

## Run locally

Requirements: Node.js and npm.

```bash
git clone https://github.com/aymanechoukri/PORTFOLIO-V2.git
cd PORTFOLIO-V2
npm install
npm run dev
```

Open http://localhost:3000.
